## About me

I'm a student developer based in Santa Clara, California. I like turning rough ideas into products people can actually use, from the first screen to the backend and final launch.

- Software engineering intern at **Venu AI**
- Building **Pick44** and **OpenRubric**
- Interested in web apps, mobile products, developer tools, and practical AI
- Currently learning more about **PyTorch** and native **iOS development**

## Selected projects

| Project | What it is |

| [**OpenRubric**](https://github.com/aaditmehtacoder/openrubric) | An open-source platform for live, transparent judging at hackathons and competitions. |
